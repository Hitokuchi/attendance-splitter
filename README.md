# 勤怠CSV分配ツール

固定勤務時間 `09:00-17:40`、固定休憩 `11:50-12:40`、1日 `470分` として、対象月の営業日数と契約比率から契約別の勤怠CSVを生成する静的Webアプリです。

## 使い方

1. `index.html` をブラウザで開く。
2. 対象月、契約名、割合 `n` を入力する。
3. 割合の合計が `1.000000` になっていることを確認する。
4. `CSVを生成` を押す。
5. 必要に応じてCSVをコピーまたはダウンロードする。

## 仕様

- デフォルトの割合は、契約A `0.1`、契約B `0.2`、契約C `0.05`、契約D `0.05`、契約E `0.05`、契約F `0.05`、契約G `0.15`、契約H `0.35` です。
- 土日と日本の祝日を休業日として扱います。
- 日本の祝日は `https://holidays-jp.github.io/api/v1/date.json` から取得します。
- 祝日APIを取得できない場合や会社独自の休業日がある場合は、追加の休業日に `YYYY-MM-DD` を1行ずつ入力してください。
- 契約は入力順に連続して割り当てます。
- 生成後に、丸め後の契約別合計分数を表示します。
- 同じ日に契約が切り替わる場合は、同一日付で複数行を出力します。
- 休憩時間をまたぐ行は、開始時刻と終了時刻だけを出します。勤務時間の計算上は `11:50-12:40` を除外しています。
